<h1>🪙 The Converter </h1>
<p align="justify">Uma aplicação web moderna e intuitiva para conversão de moedas em tempo real. Desenvolvida com foco em precisão financeira, dinamismo de interface e consumo de APIs externas. </p>

<br>

<h2>📌 Sobre o Projeto</h2>
<p align="justify">O The Converter permite converter valores entre diversas moedas globais (como Real, Dólar Americano, Dólar Canadense, Euro e Libra Esterlina) de forma dinâmica e instantânea.  A conversão é calculada utilizando taxas de câmbio atualizadas diretamente via API. Além do cálculo automático, a aplicação conta com a alteração dinâmica da interface (bandeiras e símbolos monetários) e formatação de valores nativa. </p>  

<br>

<h2>🛠️ Tecnologias Utilizadas</h2>
<ul>
  <li><b>HTML5:</b> Estruturação semântica da aplicação.</li>
  <li><b>CSS3:</b> Estilização, layout responsivo e transições sutis nos elementos.</li>
  <li><b>JavaScript (ES6+):</b> Lógica do projeto, manipulação do DOM e requisições assíncronas.</li>
  <li><b>API Fetch / Async-Await:</b> Integração assíncrona com a API externa de cotações em tempo real.</li>
  <li><b>Intl.NumberFormat:</b> API nativa do JavaScript para formatação internacional precisa de moedas locais.</li>  
</ul>

<br>

<h2>✨ Funcionalidades e Destaques</h2>
<ul>
  <li>🔄 Conversão Multimoedas em Tempo Real: Conversão precisa entre qualquer par de moedas suportado utilizando a taxa base atualizada.</li>
  <li>🌐 Consumo de API Externa: Integração com a API MoneyConvert via fetch assíncrono para obter cotações sempre atualizadas.</li>
  <li>🎨 Interface Dinâmica: Atualização imediata dos nomes, imagens e bandeiras das moedas ao selecionar as opções.</li>
  <li>💲 Formatação Internacional de Valores: Uso de Intl.NumberFormat para exibir automaticamente a moeda com a formatação e o símbolo adequados a cada país (ex: R$, $, €, £).</li>
  <li>🛠️ Tratamento de Dados e Erros: Sanitização de entradas (suporte automático a vírgula/ponto) e validação de valores numéricos antes da requisição.</li> 
</ul>
